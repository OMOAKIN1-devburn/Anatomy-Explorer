I can see the cause now. That button is sized in rem (text-sm), so on a phone it gets multiplied by the phone boost and by A+, and it can grow wider than half the screen. className="labels-toggle absolute right-3 top-3 z-[5] flex items-center gap-2 ...

Edit 2: index.css

Press Ctrl + End and paste this at the very bottom:

css
@media (pointer: coarse) {
  .labels-toggle {
    top: auto !important;
    right: auto !important;
    bottom: 0.75rem !important;
    left: 0.75rem !important;
    max-width: calc(100% - 7rem);
    text-align: left;
    line-height: 1.25;
  }
}
Laptops keep the button at the top right, as it is now.
Phones, in both normal and Desktop mode, get it at the bottom-left, with its width limited so it can’t run into the zoom buttons.
